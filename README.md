# Sc3p73r Portfolio (Next.js + MUI)

Personal portfolio built with **Next.js 15**, **React 19**, and **Material UI** — styled like a frontend DevOps dashboard (terminal panels, pipeline status, deployment cards).

## Stack

- Next.js App Router
- MUI 6 + Emotion
- TypeScript

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Assets

Static images live under `public/src/` (png, webp, svg).

## Legacy

The previous static HTML site is in `legacy/` for reference.
